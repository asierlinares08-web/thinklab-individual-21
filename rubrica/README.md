# Rúbrica de autoevaluación

1. Abre `rubrica-individual.html` en Firefox o Chrome.
2. En **«Nom i cognoms»** escribe tu nombre completo.
3. Pulsa **«Desa fitxer (.txt)»** y guárdalo aquí como `seguiment-individual.txt`.
4. Cada vez que vuelvas: abre el HTML → **«Obri fitxer»** → elige `seguiment-individual.txt` → marca → **«Desa fitxer»** → `git commit`.

Estados de cada actividad: *Pendent* · *Feta correctament* · *No feta correctament*.
Solo se marca *Feta correctament* cuando la evidencia está citada en el `.md` (ver `docs/seguiment-rubrica.md`).
Si el profesor la revisa: marcar *«El professor l'ha revisada»* y el resultado que te diga.
